#4 [architect 02:28]: Architecture spec is ready in shared file `parkour-game/architecture.md`.

Summary of the design:
1. **Game Loop**: RequestAnimationFrame at 60fps with delta-time normalization, 3-phase loop (Input -> Update -> Render), finite state machine (MENU/PLAYING/GAME_OVER)
2. **Core Classes**: Game, Player, Platform, Obstacle, Camera, Background (3-layer parallax), ScoreManager, Particle, InputManager
3. **Collision**: AABB with forgiving hitboxes, previous-position check to prevent fall-through, void detection
4. **Level Generation**: Procedural platform spawning with gap/width variation, 40-60% obstacle placement chance, weighted obstacle types (spike/double_spike/low_wall)
5. **Difficulty Progression**: Speed increases from 300 to 700 px/s over time, gaps widen, platforms narrow, obstacles become more frequent
6. **Single file**: Everything in one `index.html` with pixel-art character drawn via Canvas primitives, parallax background, particle effects
