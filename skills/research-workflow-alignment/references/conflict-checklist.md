# Conflict Checklist

Use this checklist when the team has multiple drafts, revised numbers, or a recent research pivot.

## 1. Scope

- What exact section, figure, table, or claim is being aligned?
- Which file currently appears to own it?
- Which newer file may have superseded it?

## 2. Numerical Consistency

- Do the manuscript numbers match the latest analyst file?
- Do summary messages in chat match the shared file?
- Are related counts internally coherent?
  - absolute count vs percentage
  - building share vs population share
  - daytime vs nighttime comparison
  - table values vs figure annotations

## 3. Narrative Consistency

- Does the framing still match the current research design?
- Has the project pivoted but older terminology remained in the draft?
- Are research questions, hypotheses, and section headings still aligned?

## 4. Version Consistency

- Is the team still referencing `v1` after `v2` was produced?
- Did an integrated manuscript absorb the newest specialist draft?
- Is there a draft that should be treated as deprecated?

## 5. Handoff Consistency

- Does the next owner know which file to read?
- Does the next owner know what exact output is expected?
- Is there a missing approval from `author` or the user?

## Resolution Rule

- Name one source of truth.
- Name one owner for the next move.
- Name one expected output.
- State what should be ignored from now on.
